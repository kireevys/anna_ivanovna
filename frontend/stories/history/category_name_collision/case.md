# Категория с именем "Без категории"

## Предусловие
История в состоянии Loading (пустой список, статус Loading)

## Шаги
1. Приходит Loaded с записью, где один расход лежит вне категорий,
   а другой — в категории, названной "Без категории"

## Ожидаемый результат
- Обе записи попадают в одну категорию "Без категории"
- Ни одна не теряется
