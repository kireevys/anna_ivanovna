# Группировка расходов по категориям

## Предусловие
История в состоянии Loading (пустой список, статус Loading)

## Шаги
1. Приходит Loaded с записью, где расходы лежат в двух категориях
   и один расход без категории

## Ожидаемый результат
- "Без категории" идёт первой, остальные категории по алфавиту
- Расходы внутри категории отсортированы по названию
